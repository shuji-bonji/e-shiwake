# 請求書

## 請求書機能とは

請求書機能では、取引先への請求書を作成・管理できます。
作成した請求書は印刷やPDF保存が可能で、売掛金仕訳・入金仕訳を自動生成できます。

> **INFO**: 請求書の変更は自動保存されるため、手動で保存する必要はありません。

## 請求書一覧

サイドバーから「請求書」を選択すると、請求書一覧が表示されます。

- 年度ごとに請求書を管理
- ステータス（下書き・発行済み・入金済み）でフィルタリング
- 請求書番号、発行日、取引先、金額、ステータスを一覧表示

## 請求書の作成

1. 「新規作成」ボタンをクリック
2. 請求書番号が自動採番されます（必要に応じて変更可能）
3. 基本情報（発行日、支払期限、取引先）を入力
4. 明細行を追加し、品名・数量・単価を入力
5. 必要に応じて備考を入力

> **TIP**: 取引先は事前に「取引先管理」で登録しておくとスムーズです。請求書画面から直接追加することはできません。

## 請求書のコピー

既存の請求書をコピーして新しい請求書を作成できます。毎月同じ取引先に類似の請求書を発行する場合に便利です。

1. 請求書一覧でコピーしたい請求書のコピーボタン（📋）をクリック
2. コピーされた請求書の編集画面が開きます
3. 必要に応じて明細行の内容を修正

> **INFO**: コピー時に以下の項目が自動的にリセットされます：発行日→今日の日付、支払期限→翌月末、請求書番号→自動採番、ステータス→下書き、仕訳紐付け→クリア

> **TIP**: 取引先・明細行・備考はそのまま引き継がれるので、日付と明細の数量・単価を修正するだけで新しい請求書が完成します。

## 入力項目

| 項目       | 説明                               | 例                         |
| ---------- | ---------------------------------- | -------------------------- |
| 請求書番号 | 請求書を識別する番号（自動採番）   | INV-2026-0001              |
| 発行日     | 請求書の発行日                     | 2026-01-15                 |
| 支払期限   | 支払いの期限日                     | 2026-01-31                 |
| 取引先     | 請求先（登録済みの取引先から選択） | 株式会社サンプル           |
| 備考       | 振込口座や注意事項など             | 振込手数料はご負担ください |

## 明細行

「行を追加」ボタンで明細行を追加できます。

| 項目             | 説明                             | 例               |
| ---------------- | -------------------------------- | ---------------- |
| 日付             | 作業期間や対象月など（自由記述） | 1月分、1/1〜1/31 |
| 品名・サービス名 | 提供した商品やサービスの名称     | システム開発     |
| 数量             | 数量（小数可）                   | 1、1.5           |
| 単価             | 1単位あたりの価格（税抜）        | 100,000          |
| 税率             | 消費税率（10%または8%）          | 10%              |
| 金額             | 自動計算（数量 × 単価）          | 100,000          |

> **INFO**: 金額は数量と単価から自動計算されます。消費税は税率ごとに集計され、端数は切り捨てで計算されます。

## ステータス管理

請求書には3つのステータスがあります。

| ステータス | 説明                   | 操作                     |
| ---------- | ---------------------- | ------------------------ |
| 下書き     | 作成中の請求書         | 「発行済みにする」で次へ |
| 発行済み   | 取引先に送付した請求書 | 「入金済みにする」で完了 |
| 入金済み   | 入金が確認された請求書 | 完了状態                 |

> **TIP**: ステータスは請求書編集画面のヘッダーから変更できます。

### ステータスを戻す

操作ミスなどで進めすぎたステータスは、「ステータスを戻す」ボタンで 1 段階前に戻せます（入金済み → 発行済み、発行済み → 下書き）。確認ダイアログで「戻す」を選ぶと反映されます。

> **WARNING**: ステータスを戻しても、その請求書から作成した仕訳（売掛金仕訳・入金仕訳）は削除されません。仕訳も取り消す場合は、仕訳帳で該当の仕訳を削除してください。

## 仕訳の自動生成

請求書から以下の仕訳を自動生成できます。

> **WARNING**: 仕訳を生成するには、請求書に取引先が設定されている必要があります。取引先が未設定のまま仕訳ボタンを押すと、案内が表示され仕訳は作成されません。

取引先をまだ登録していない場合は、取引先欄の「取引先を追加」から取引先管理に移動できます。取引先を保存すると元の請求書に戻り、作成した取引先が自動的に選択されます。

### 売掛金仕訳

「売掛金仕訳」ボタンをクリックすると、売上計上の仕訳が作成されます。

- 借方：売掛金（税込合計）
- 貸方：売上高（10%対象、8%対象それぞれ）
- 摘要：「売掛金計上 INV-XXXX-XXXX」（請求書番号が自動設定）

### 入金仕訳

入金済みステータスの請求書で「入金仕訳」ボタンをクリックすると、入金日と入金額を指定して仕訳を作成できます。

- 借方：普通預金（入金額）
- 貸方：売掛金（入金額）
- 摘要：「入金 INV-XXXX-XXXX」（請求書番号が自動設定）

入金額の初期値は未入金残額（税込合計 − 作成済み入金仕訳の合計）です。分割入金の場合は今回の入金額に書き換えてください。

### 売掛金仕訳の二重作成防止

売掛金仕訳は請求書 1 件につき 1 件です。作成済み（請求書に記録した仕訳 ID の仕訳が仕訳帳に存在する）の場合、「売掛金仕訳」ボタンは無効になり、「作成済み」と表示されます。仕訳帳でその仕訳を削除すると、ボタンは再び有効になります。

### 売掛金仕訳を作成したあとに請求書を変更した場合

売掛金仕訳を作成したあとで明細行・取引先・発行日・請求書番号を変更すると、保存のたびに仕訳の日付・取引先・摘要・明細行を請求書の内容で自動的に上書きし、「売掛金仕訳が作成済みのため、仕訳の内容を請求書に合わせて更新しました」と通知します。ステータスの変更は仕訳に写らないため対象外です。

> **WARNING**: この自動更新は、仕訳帳で手で直した勘定科目や金額も上書きします。仕訳帳側を直したい場合は、先に請求書の内容を確定させてください。証憑の添付は保持されます。

### 入金仕訳の警告

同じ請求書から入金仕訳を二重に作成しないよう、作成済みの入金仕訳が 1 件以上ある場合は、ダイアログに入金仕訳の一覧、入金合計、税込合計、未入金残額を表示します。分割入金など意図的な場合は「作成」で続行できます。入金が税込合計に達している場合は、ボタンが「それでも作成」に変わります。「仕訳帳で検索」を押すと、仕訳帳で請求書番号を検索した状態に移動します。

> **INFO**: 作成済みかどうかは、請求書に記録した仕訳 ID で判定します。この機能より前に作成した入金仕訳は請求書に記録されていないため、判定の対象になりません。

### 請求書を削除する場合

請求書一覧から請求書を削除すると、その請求書から作成した売掛金仕訳も一緒に削除され、結果を通知します（削除ダイアログに対象の仕訳を表示します）。入金仕訳は実際の入金を表すため削除せず、仕訳帳に残ります。

## 適格請求書（インボイス）チェック

適格請求書発行事業者として登録番号を設定している場合、請求書が適格請求書の記載要件を満たしているかを自動チェックします。

要件を満たしていない場合、請求書編集画面に警告メッセージが表示されます。また、印刷時にもトースト通知で注意喚起されます。

チェックされる項目は以下の通りです。

| チェック項目                 | 内容                                   |
| ---------------------------- | -------------------------------------- |
| 発行事業者の氏名・名称       | 事業者情報の「氏名」が入力されているか |
| 登録番号の形式               | 「T」+ 13桁の数字になっているか        |
| 取引先（交付先）の氏名・名称 | 取引先が選択されているか               |
| 取引内容（品名・サービス名） | 明細行の品名が空でないか               |

> **INFO**: 登録番号が未設定（免税事業者）の場合、チェックは行われません。適格請求書発行事業者の登録番号は「データ管理」ページまたは「青色申告決算書」の設定から入力できます。

> **TIP**: このチェックは情報提供のみで、請求書の作成・印刷をブロックするものではありません。免税事業者の方も通常通り請求書を作成・印刷できます。

## 印刷・PDF保存

請求書編集画面の「印刷」ボタンから、請求書を印刷またはPDFとして保存できます。

1. 「印刷」ボタンをクリック
2. ブラウザの印刷ダイアログが表示されます
3. プリンターを選択して印刷、または「PDFとして保存」を選択

> **INFO**: 印刷時には事業者情報（事業者名、住所、電話番号など）が表示されます。事業者情報は「データ管理」ページで設定できます。

## 請求書番号の採番ルール

新規作成時、請求書番号は以下のルールで自動採番されます。

- 形式：INV-{年}-{4桁の連番}
- 例：INV-2026-0001、INV-2026-0002
- 年度ごとに連番がリセットされます
- 採番後に手動で変更することも可能です

## 注意事項

> **WARNING**: 請求書を削除すると復元できません。削除前に必要なデータをエクスポートしてください。

> **INFO**: 取引先を削除しようとした場合、その取引先を使用している請求書があると削除できません。先に請求書を削除または取引先を変更してください。
